# Contributing

Thank you for taking an interest in NeuroPhysics.

The project is experimental and still under active development. Contributions, corrections, ideas, and constructive feedback are welcome.

## Before opening an issue

- Check whether the issue has already been reported.
- Include a concise description of the expected and actual behaviour.
- Include a minimal reproduction when reporting a bug.
- Mention the Roblox environment and relevant settings.

## Pull requests

- Keep changes focused.
- Use clear names and preserve the existing naming style.
- Explain why a change is needed.
- Add or update examples and tests where practical.
- Avoid introducing dependencies without discussing them first.

Please remember that not every subsystem has complete test coverage yet.
